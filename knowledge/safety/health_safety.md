# SmartHealth AI Safety Guidelines

## Application Purpose

SmartHealth AI is an educational and wellness-oriented
software application.

Its machine-learning outputs represent model-generated
possibilities based on the application's dataset.

They are not medical diagnoses.

## Symptom Analysis

The symptom-analysis module identifies patterns learned from
the training dataset.

A model prediction does not confirm that a person has a disease.

Users should consider appropriate professional medical evaluation
when symptoms are concerning or persistent.

## Nutrition

BMI, BMR, TDEE, calorie estimates, and food recommendations
are computational estimates.

Individual nutritional requirements can vary significantly.

These calculations should not be treated as medical prescriptions.

## Allergies

The application can filter foods using the allergy information
entered by the user.

Users should always verify food ingredients and preparation
methods independently.

The application's allergy filter should not be considered a
guarantee that a food is safe.

## Traditional Wellness Information

Ayurveda and homeopathy sections provide traditional or
educational information.

They should not be interpreted as proven treatments or as
replacements for professional medical care.

## Data Privacy

Users should avoid entering unnecessary sensitive personal
information.

Applications handling real health information should implement
appropriate security controls, access controls, encryption,
secure deployment practices, and data-minimization principles.

## Emergency Situations

SmartHealth AI should not be used as an emergency decision-making
system.

If someone experiences a serious or rapidly worsening medical
problem, they should seek appropriate emergency medical care.

## AI Limitations

Machine-learning systems can produce incorrect predictions.

Results can be affected by:

- Training-data limitations
- Dataset quality
- Missing symptoms
- Incorrect user input
- Population differences
- Model limitations

Users should treat model outputs as informational rather than
certain conclusions.
